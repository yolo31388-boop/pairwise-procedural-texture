# 游戏内程序化纹理生成与材质系统

## 项目描述

游戏内程序化纹理生成与材质系统的bug修复项目。核心模块 `rendering/texture.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 纹理生成完全没做贴图都是预绘的
- 材质合成完全没做只有颜色没有质感
- 噪声函数完全没做用的是简单随机数
- 纹理映射完全没做贴图拉伸变形
- 纹理图集完全没做每个纹理都是单独的文件

## 运行测试

```bash
python -m pytest tests/test_procedural_texture.py -q
```
